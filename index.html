E-commerce Business system Client project

ILANA — E-Commerce Platform

A production-grade e-commerce site built for Ilana, a Kenyan jewellery retailer, with real Safaricom M-Pesa Daraja STK Push payments (sandbox-first), an admin dashboard, and WhatsApp enquiries.
